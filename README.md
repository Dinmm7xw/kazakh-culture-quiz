# 🇰🇿 Бақыт Дөңгелегі & Ұяшықтар: Қазақ Мәдениеті (Викторина)

16 студентке арналған, **Колесо Фортуны + Құпия Ұяшықтар (Mystery Cells) + Мобильді Буззер жүйесі (Кім бірінші басады?)** бар интерактивті викторина ойыны. 
Vercel арқылы бүкіл аудиторияға сілтеме таратып ойнауға толық дайын!

## 📱 МОБИЛЬДІ БУЗЗЕР ЖҮЙЕСІ (Vercel арқылы)
1. **Сілтемені тарату:** Жоғарғы оң жақтағы **«🔗 Топқа сілтеме көшіру»** батырмасын басып, WhatsApp/Telegram топқа жібересіз (мысалы: `https://ваша-ссылка.vercel.app/?role=player`).
2. **Студенттің әрекеті:** Телефоннан ашып, 16 студент ішінен өз атын бір-ақ рет таңдайды.
3. **Жауап беру:** Экранда үлкен **«🚨 ЖАУАП БЕРЕМІН!»** қызыл түймесі шығады.
4. **Кім бірінші басты?:** Админ экранында миллисекундтық дәлдікпен кім бірінші басқаны көрініп, сол студент автоматты түрде белсенді жауап беруші болып бекітіледі!

## 🚀 Vercel-ге шығару:
Жобада стандартты `vite` қолданылған, сондықтан Vercel-ге деплой жасау өте оңай:
```bash
# 1-тәсіл: Vercel CLI арқылы
npm i -g vercel
vercel

# 2-тәсіл: GitHub-қа салып, vercel.com сайтынан 'Import' батырмасын басу.
```

## 💻 Жергілікті іске қосу:
```bash
npm run dev
```
Браузерде: **`http://localhost:5173/`**
